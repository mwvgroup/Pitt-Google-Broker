# LSST_V01_SNIa_vs_NONSNIa_forPittGoogle

This directory contains a trained [SuperNNova](https://github.com/supernnova/SuperNNova) model
(vanilla_S_0_CLF_2_R_none_photometry_DF_1.0_N_cosmo_lstm_32x2_0.05_128_True_mean.pt) and related output/log files.

The model was trained by Kyle Mo.
It was trained on [ELAsTiCC2](https://portal.nersc.gov/cfs/lsst/DESC_TD_PUBLIC/ELASTICC/ELASTICC2_TRAINING_SAMPLE_2) data.

Class0 is the SN Ia probability score.
